# CaaM 1.0.0

First stable public release of CaaM — Controller as a Mouse.

## Included

- system-wide controller-based mouse, scrolling, keyboard and media control
- Xbox, DualSense, DualShock, Nintendo Switch and generic controller support
- automatic controller handoff to games
- PlayStation touchpad mouse support
- configurable button mappings, sensitivities and handedness
- Windows startup, priority startup and lightweight tray operation
- modern light/dark/system themes, minimal fallback and custom CSS
- German and English interface
- settings reset, mapping reset, backup and restore

## Distribution

The Windows x64 build is portable and self-contained. Download `CaaM-v1.0.0-win-x64.zip`, extract it and run `CaaM.exe`. Windows may display a SmartScreen notice because the executable is not code-signed.
